# HotpotQA / HoVer BM25 完成与正式实验准备

两个检索任务共用的 Wikipedia 2017 索引已构建并验收：**5,233,330 篇文档、
169,530,287 个分词、2,549,605 个语干词项、131,822,459 条倒排记录**。
五个原生索引文件共 1,118,933,634 字节。完整资源及缓存保持忽略，不进入 Git。
本记录补充此前的[发布验收](../gepa_paper_publication_20261031/README.md)，保留其历史快照。

## 保留的作者语义

使用已固定的作者代码和 bm25s 0.2.12。语料字节哈希及文档顺序不变，文本仍按
`title | joined text` 构造；调用原生 `bm25s.tokenize`、英文停用词及 PyStemmer English。
BM25 仍为 Lucene，`k1=0.9`、`b=0.4`、float32 分数及 int32 索引，查询使用作者入口的
单线程排序、去重和 k=7/10。HotpotQA 实际导入的就是 HoVer 的同一个 search 函数。

原始全量构建器的 8GiB 可用内存检查未被绕过或删除。另行使用归档的离线资源工具，
分批调用同一原生分词器，磁盘保存 token 和 CSC 缓冲区，并调用原生 IDF、词频和
TFC 计算函数。只改变存储和词项列编号；文档编号、数学计算和库的最终文件格式不变。
原生默认加载器可直接读取，正式运行加载代码未修改。构建中采样到的最大 RSS 约 1.73GiB。

该失败及后续成功的原始记录均保留在忽略目录。

未在这台机器上另建一份全语料、全内存原生参考索引。因此验收依据是上述完整小样本

完整测试的 3 个已知警告不影响通过；没有宣称全部历史评分回放通过。
