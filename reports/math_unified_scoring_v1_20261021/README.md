## 实现和论文语义

两仓新增各自独立的 `math_scoring` 包，共 10 个模块。9 个公共模块字节一致，仅本仓旧内核/呈现规范化的导入绑定不同；无兄弟仓运行时 Python 依赖。接口、资源上限、版本和迁移合同见 [规范](../../docs/math_unified_scoring_v1.md) 与 [政策冻结记录](../../configs/math_unified_scoring_v1.json)。所有使用均需显式传入政策；现有生产/历史入口继续调用原评分路径。

| 政策 | 语义及来源 | 用途 |
|---|---|---|
| `paper_extracted_exact_v1` | 统一无 Gold 提取、固定呈现规范化、精确字符串相等；不导入 SymPy | 建议下轮论文对照的候选 Primary，尚未启用 |
| `maspo_compat_v1` | 完整保留 MASPO 两个纯函数的 AST 和原始不安全规则 | 仅实现兼容性参考；禁止用于默认评分和投票 |
| `math_semantic_v1` | 同一提取器、对象类型、直接/精确有理数检查、固定版 Math-Verify、硬资源边界 | 建议数学语义 Secondary，尚未启用 |

[MASPO 官方固定提交](https://github.com/wangzx1219/MASPO/blob/90e8c6fcc08c1e8f9a61740b296d4fab9e09e2d2/utils.py) 的最终无 Judge MATH 路径确实是提取、规范化、字符串相等；优化器中的 LLM 比较属于另一条路径。本次仅隔离移植两个纯函数，没有导入模型运行代码。固定提交为 `90e8c6fcc08c1e8f9a61740b296d4fab9e09e2d2`，源文件 SHA-256 为 `e3c4e8ba46ea7619b5a0abae4bc9b762e840aecc209eee165cad4623596d8955`。两函数 AST 完全相同，全部 3,492 份响应与独立执行的固定上游纯函数逐项一致。

B 保留最后一个 answer 标签、**第一个**有限嵌套 boxed、最后一行 30 字符回退、方括号转圆括号、大小写折叠、裸整数列表排序。它不识别本实验常用的 Final answer 标签。本语料上 B 的低匹配率主要是输出协议不兼容，不能解读为 MASPO 方法能力低。括号闭合、变量大小写和裸列表顺序混淆是上游兼容规则的已知数学风险，合成用例明确保留该行为；不能将 B 视为数学等价真值。

[C-EVOLVE 正式论文 Appendix B.2](https://proceedings.iclr.cc/paper_files/paper/2026/file/3f1351a10a3f904e6f3845a94275a909-Paper-Conference.pdf) 描述提取最终答案后 exact string match。未找到足以逐行核对的正式提取/规范化代码，故 A 的来源级别为 **`paper_description_only`**，不能声称作者代码完全复现。C 的类型、有理数和有界子进程是项目自身扩展。[Math-Verify](https://github.com/huggingface/Math-Verify) 固定为 0.6.0，SymPy 1.14.0、latex2sympy2_extended 1.0.9、ANTLR4 4.13.2、mpmath 1.3.0，依赖未升级。

本报告的“历史 V7”专指原审计冻结的 flexible V7 输出协议加 domain V2 内核，不能与 GEPA 文件名 `scoring_v7.py` 的后续恢复政策混为一谈。区间/幂证书、预测有效性和旧提取模块均原样保留。

新接口把输出有效性和正确性分开记录。`CORRECT`、`INCORRECT`、`INVALID_OUTPUT` 为已决；`UNSUPPORTED`、`EVALUATOR_TIMEOUT`、`INFRASTRUCTURE_FAILURE`、`REFERENCE_INVALID` 的 `correct` 均为 null。结果对象禁止隐式转 bool，`.binary()` 对未决抛出明确异常。独立 `compare_answers` 检查类型和双向等价；不能把非对称 Gold 评分直接用于投票。

提取器不接收 Gold 或政策 ID。显式冲突答案按呈现规范化后字符串检查，不能挑选碰巧匹配 Gold 的候选；中间推导不作为最终声明。两元素圆括号默认无法区分有序对/开区间，C 返回未决，只有显式冻结的类型元数据能解除歧义。截断、未闭合和缺失最终声明保留原因码。

## 差异、人工可读复核与局限

已对分类样例作人工可读复核；脱敏 hash、结果和说明见 [manual_review.json](manual_review.json)。它是典型病例复核，不是全语料独立数学真值标注。

- A 与 C 有 **288** 份“C 已确认等价、A 字符串不等”记录。不能把所有不等字符串统称为数学误判。A 有意不消除分数写法、代数变形等全部数学差异。
- 新旧提取载荷字节不同共 **887** 份，包含空白/包装变化，不能等同 887 份判定变化。已决判定转移和未决变化另行报告。
- C 的 **44** 份未决为 21 份固定解析器不支持、23 份一般 Float 表达式不能用有界精确路径证明。终端子集有 25 份。Unicode 无穷符号、带单位小数、文本标签等限制如实保留，不按 Test 分数追加特判。
- A/C 共有 **18** 份格式无效：7 截断、6 缺失明确最终声明、5 最终载荷含散文。存在 **4** 份“旧数学路径阳性但新格式无效”的响应；包含可读的正确数学片段，并不意味着模型数学错误。尾随未标明的解释/单位、跨行的非明确结论仍可能被保守拒绝。
- B 阳性、C 阴性共 **5** 份，样例来自提取边界或关系式/标量类型区别，不能全标为数学假阳性。本语料未据此建立上游括号错误的历史发生率；该风险由独立合成对照证明。
- 在旧 V7/新 C 共同已决样本中没有旧阳性→新阴性，但仍有旧阳性变为未决。未建立穷尽性的独立数学 Oracle，**不声称不存在新增假阳性或假阴性**。字符串政策相对数学语义的拒绝、保守格式拒绝及固定内核支持边界均已披露。
